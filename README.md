# 💱 Currency Converter Web App

A simple and interactive currency converter web application that converts one currency to another using real-time exchange rates.

---

## 🚀 Features

- Convert between multiple international currencies
- Real-time exchange rates using ExchangeRate API
- Swap currencies instantly
- Displays conversion rate details
- Clean and user-friendly interface
- Responsive layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- ExchangeRate API

---


---

## ⚙️ How It Works

1. Enter an amount in the "From" input field.
2. Select the source and target currencies.
3. The app fetches live exchange rates from the API.
4. Converted value is calculated automatically.
5. Exchange rate details are displayed.
6. Use the **Swap** button to exchange currencies instantly.

---

## 🔗 API Used

**ExchangeRate API**

https://open.exchangerate-api.com/v6/latest/{BASE_CURRENCY}


---

## 🖥️ How to Run the Project

1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Enter the amount and select currencies
4. View real-time converted values instantly

_No installation or dependencies required._
